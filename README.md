## ✨ 功能特性

### 🎭 角色系统
- **6 位独特角色**，每位拥有独立剧本、隐藏任务与秘密线索
- 自驱式分幕阅读：角色按幕推进，逐步解锁剧情
- 角色锁定 PIN 码机制，防止偷看他人剧本

### 🏠 主持人视图
- **案件总览**：完整案件真相 + 时间线复盘
- **全角色剧本**：主持人可查看任意角色剧本
- **标准答案**：所有问答终局的标准答案
- **犯罪地图**：可视化密室关系图与证据链

### 🗺️ 调查系统
- 交互式犯罪现场地图（客厅、卧室、配餐间、露台）
- 点击房间节点 → 查看场景描述与证据
- 关键证据高亮标记，支持密室推理分析

### 🔍 线索系统
- 公共线索（全员可见）+ 私密线索（角色独有）
- 线索可在调查阶段分享给其他玩家
- 线索解锁联动 — 发现某线索后可解锁隐藏剧情

### 🎯 任务系统
- 角色个人目标（隐藏 / 探查 / 保护 / 陷害）
- 分幕揭示，优先级标记
- 实时目标追踪

### 🗳️ 投票系统
- 终局凶手投票（6 选 1）
- 实时投票结果展示
- 投票原因记录

### ❓ 问答终局
- 每位角色 5 道专属问题（身份 / 关系 / 手法 / 物证 / 动机）
- 每题 20 分，满分 100
- 提交后即时评分 + 答案解释

## 🎮 游戏流程

```
角色选择 → 分幕阅读 → 线索搜查 → 集体讨论 → 投票指认 → 问答终局 → 真相揭晓
```

1. **角色选择** — 6 名玩家各自选择角色，获得 4 位 PIN 码锁定
2. **分幕阅读** — 按幕推进剧本，每幕解锁新线索与新目标
3. **线索搜查** — 探索犯罪现场的 4 个房间，发现 10+ 条证据
4. **投票指认** — 每位玩家投票指认真凶
5. **问答终局** — 5 题考验推理，即时评分
6. **主持人复盘** — 揭开完整真相与时间线

## 📝 设计理念

- **自驱式阅读** — 玩家按自己的节奏阅读剧本，无需 GM 逐段分发
- **渐进式信息释放** — 分幕 + 线索解锁确保所有玩家同时掌握关键信息
- **主持人友好** — DM 面板集成案件全览、标准答案、地图、全角色剧本
- **移动端适配** — 响应式设计，手机 / 平板均可流畅运行
